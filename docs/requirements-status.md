# ReelMate 요구사항 및 WBS 상태

검증 대상은 `C:\reelmate`의 신규 구현입니다. 제공된 화면 시안과 두 기준 PDF를 사용했습니다. 초기 ZIP과 실제 촬영 자료가 없어 합성 영상, 한글 자막, 합성 음성으로 기능을 검증했습니다.

| 범위 | 구현 및 확인 결과 |
|---|---|
| FR-001, 002, 005, 009 | 프로젝트 복원, 원본과 레퍼런스 분리, 영상 메타데이터·썸네일, PDF/TXT 가이드와 직접 입력 구현. Edge에서 원본 2개, 레퍼런스 3편, TXT 가이드 등록 확인 |
| FR-003, 004 | FFmpeg 컷 전환 후보·평균 컷 길이와 레퍼런스 근거, CLIP 장면 및 제품 시점 추정, 자막 트랙·선택 OCR, 사용자 관찰 편집 구현. 합성 레퍼런스 측정, 스타일 승인·선택, JSON 왕복 확인. 실제 릴스의 스타일 품질 및 OCR 인식은 미검증 |
| FR-006, 007, 008 | Windows에서 공개 CLIP 가중치로 실제 프레임 추론. 인접 라벨의 그룹화, 후보 썸네일·모델·유사도, 수동 라벨·시간·제외 구현. 실제 제품 장면 분류 품질은 미평가 |
| FR-010, 012 | 수동 규칙 작성·승인, Gemini 규칙 및 편집안 UI·서버 연동. 허용되지 않은 후보 및 실패 응답에서 이전 데이터 보존 확인. Gemini 서버 키·모델 미설정으로 실 API 결과 미검증 |
| FR-011 | 선택 Whisper 전사, 컷 시간에 맞춘 자막 가져오기, 수동 자막 편집 구현. Windows 합성 음성이 있는 MP4로 실제 모델 전사와 타임코드 확인 |
| FR-013, 014, 016, 017 | 범위·ID·중복·길이·잠금 검사, 필수 규칙과 타임코드, 직접 검수 기록, 컷·자막 편집과 잠금·선택 컷 재편집 확인 |
| FR-015, 019, 020 | Windows MP4 및 대체 ZIP 생성. 합성 원본으로 10초·540×960·30fps·컷 순서·오디오·한글 자막 확인. WebM 원본으로 1:1·16:9 출력과 65프레임 길이 확인. 동일 버전의 독립 자막·컷시트·EDL·보고서, 이전 버전 보존 및 브라우저 재다운로드 확인 |
| FR-018 | Windows CapCut 9.x 시험용 초안에 컷과 텍스트를 독립 트랙으로 구성하는 ZIP과 적용 도구 구현. 활성 타임라인·루트 복사본 동기화와 백업을 합성 초안으로 검증. 실제 CapCut 열기·편집·저장·재열기는 대기 |
| NFR-001~009 | 5단계 UI와 좁은 화면, 모델·사람 판정 구분, 로컬/세션별 저장과 삭제, 비밀값 서버 관리 확인. 장시간 작업은 수행 단계 상태로 표시. 공개 환경 보안은 별도 검증 대상 |
| NFR-010 | 의존성·실행 스크립트·빌드 결과·배포 설정 준비. GitHub 원격 연결 및 Streamlit Cloud 배포 미실행 |

| WBS 게이트 | 판정 |
|---|---|
| GATE 1 CapCut | 내보내기·적용 도구 구현. [Windows CapCut 빌드와 앱에서 만든 시험용 초안](capcut-validation.md)으로 재열기 검증 필요 |
| GATE 2 데이터 | 합성 검증 통과. 실제 협찬 평가 데이터 필요 |
| GATE 3 수동 엔진 | Windows 통과. 동일 계획의 MP4·SRT·개별 클립·컷시트·EDL 검증 |
| GATE 4 AI | 부분 검증. 실제 CLIP·Whisper 추론과 Gemini 입력 검증 완료. Gemini 실 API와 실제 제품 품질 평가는 대기 |
| GATE 5 화면 통합 | Windows Edge에서 자료 등록, 실제 CLIP 후보, 규칙 승인, 스타일 저장·선택, 편집·검수, 재생·다운로드, 새로고침·서버 재시작 후 출력 복원 통과. CapCut 네이티브 및 공개 배포 검증은 대기 |

Windows에서 Python 테스트 25개, React 빌드, Streamlit AppTest와 Edge 브라우저 E2E를 통과했습니다. 테스트 환경은 Python 3.12.10, Node.js 24.22.0, Streamlit 1.66.1, FFmpeg/ffprobe 9.0.2, Edge 157.0.4341.42, Windows 맑은 고딕입니다. 390px 화면에서 프로젝트 설정, 자료 등록, 편집안 검토의 가로 넘침을 검사했습니다.
